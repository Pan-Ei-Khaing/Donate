# Shwe Myo Gyi Gine Htauk Monastic Education School

A simple public website for Shwe Myo Gyi Gine Htauk Monastic Education School in Tatkon Township, Myanmar.

## Local preview

Open `index.html` in a web browser.

## Publish with GitHub Pages

1. Push the website files to the `main` branch.
2. On GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. GitHub will show the public website URL after publishing.

## Updating photos

Approved school photos and a logo can be added later. Update the image area in `index.html` after placing the image files in an `assets/` folder.
